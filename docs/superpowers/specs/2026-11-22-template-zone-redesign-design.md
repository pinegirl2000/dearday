# 템플릿 재디자인 — 그림·글 영역 분리 설계

- 작성일: 2026-11-22
- 상태: 사용자 승인 대기
- 선행 작업: `2026-11-22-template-typography-design.md` (글꼴·자동 맞춤 `FitText` — 그대로 재사용)

## 1. 의도와 이유

템플릿 25개 중 약 10개에서 글자가 배경 그림(곰·풍선·성·리본·꽃)과 겹쳐 읽기 어렵다.
모든 카드가 "배경 한 장 위에 글자를 가운데로 흘려보내는" 한 가지 구조이고, 카드 높이가 글 길이에 따라 변하면서
배경이 `cover` 로 잘려 그림 위치까지 움직이기 때문이다.

사용자 결정(A안): **그림과 글 영역을 나눈다.** 기존 구조·레이아웃은 유지할 필요 없음. 가장 심한 것만 내리고 새로 만든다.
함께: 봉투에서 카드가 나오는 연출과 템플릿 전체를 점검한다.

## 2. 현재 상태 (원본 배경 확인 결과)

- 배경 이미지는 대부분 1240×1748(약 5:7) 세로 카드로 **이미 빈 자리(글 놓을 곳)를 갖고 디자인되어 있다.**
  예: `sage-teddy` 는 리본 프레임 안쪽, `pink-ribbon-arch` 는 아치 안 리본 아래, `teddy-blue` 는 아래 55%, `party-balloons-cake` 는 원 안 + 가운데.
- 지금은 그 빈 자리를 모른 채 위에서부터 글을 쌓고, 날짜 박스·연락처·RSVP 까지 같은 그림 위에 계속 쌓는다 → 그림과 겹침.
- 봉투 연출은 이미 있음: `InvitationView` 가 봉투(9종: Classic, Sway 색상별, Ribbon, BlackGold 등)를 먼저 보여 주고 누르면 카드가 나온다. 로컬 DB 가 없어 실제 동작은 미확인.
- `black-gold-gala` 는 겹침이 아니라 색 문제(검정 배경에 짙은 보라 글자).

## 3. 목표 / 비목표 / 실패 조건

**목표**
- 모든 템플릿에서 글자·날짜 박스·버튼이 배경 그림의 주요 요소와 겹치지 않는다
- 글 길이가 달라져도 그림 위치·비율이 변하지 않는다
- 봉투 → 카드 연출이 새 카드 구조에서 자연스럽게 이어진다 (카드가 봉투에서 올라오는 느낌)
- 25개 전부 점검: 유지 / 영역 지정 / 색 수정 / 내리고 새로 만들기 중 하나로 판정
- 내리는 템플릿을 대체할 새 템플릿은 코드(SVG·CSS)로 그린 배경 — 영역이 처음부터 정의됨

**비목표**
- 싱가포르용 신규 기능(날짜 투표, 캘린더, PayNow 등) — 별도 프로젝트
- 봉투 디자인 자체를 새로 만드는 것 (연결 연출만 손봄)
- 절대배치 보조 레이아웃(layout-3/5 등) 재설계 — 새 구조로 옮긴 템플릿은 보조 레이아웃 선택지를 제거

**실패 조건**
- 이미 발행된 카드가 깨지거나 내용이 사라짐 (모양이 바뀌는 것은 허용 — 선행 작업에서 사용자 확정)
- 긴 본문·긴 제목에서 글이 잘리거나 영역 밖으로 나감
- 그림을 살리려다 글이 지나치게 작아짐 (제목 최소 18px, 본문 최소 13px 아래로 내려가지 않음)

## 4. 접근법

| 안 | 내용 | 판단 |
|---|---|---|
| **A. 표지 + 내용 면 분리 (선택)** | 카드 위쪽은 배경 원본 비율 그대로의 "표지", 그 안의 지정된 빈 영역에 제목부만. 날짜·장소·연락처·RSVP 는 표지 아래 깨끗한 "내용 면"에 | 그림이 절대 안 움직이고 겹침이 구조적으로 불가능 |
| B. 글자 뒤 반투명 패널 | 지금 구조 유지, 글 뒤에 종이 패널 | 빠르지만 그림을 가림 — 사용자 미선택 |
| C. 전부 내리고 새로 만들기 | 코드로 그린 템플릿으로 교체 | 기존 그림 자산을 버림 — 가장 심한 것에만 사용 |

## 5. 설계

### 5.1 카드 구조 — "표지 + 내용 면"

```
┌──────────────────┐
│   (배경 그림)      │  ← 표지: 배경 원본 비율 고정(예 1240:1748), 잘림 없음
│  ┌────────────┐  │
│  │ YOU'RE..   │  │  ← 글 영역(zone): 배경마다 지정한 빈 자리
│  │  제목       │  │     라벨·부제·제목·(짧은) 본문만
│  │  본문       │  │
│  └────────────┘  │
├──────────────────┤
│  날짜 | 12 | 시간  │  ← 내용 면: 배경의 바탕색과 이어지는 단색/은은한 그라데이션
│  장소 · 지도       │     날짜 박스·장소·연락처·추가 안내·RSVP
│  연락처 · RSVP     │
└──────────────────┘
```

- 표지와 내용 면은 한 장의 카드처럼 보이도록 같은 둥근 모서리 컨테이너 안에 이어 붙이고, 경계는 배경 하단색 → 내용 면 색으로 자연스럽게 잇는다
- 본문이 글 영역에 다 안 들어가면: 글 영역에는 제목부까지만 두고 **본문 전체를 내용 면 맨 위로 내린다** (잘라서 나누지 않음)

### 5.2 배경별 글 영역 데이터

`BackgroundMeta` 에 추가:

```ts
interface TextZone { x: number; y: number; w: number; h: number; align?: 'left'|'center'|'right'; valign?: 'top'|'center'|'bottom' }  // 모두 배경 대비 %
zone?: TextZone;          // 없으면 기존 흐름형 렌더(겹침 없는 템플릿은 그대로)
aspect?: number;          // 가로/세로. 기본 1240/1748
panelColor?: string;      // 내용 면 바탕색 (배경 하단색과 맞춤)
```

초기 추정치(구현 시 화면에 영역 테두리를 띄워 보정):

| 배경 | 그림 위치 | 글 영역(대략) |
|---|---|---|
| teddy-pink | 왼쪽 위 풍선·곰 | 오른쪽 아래 — x 40~94%, y 30~92%, 오른쪽 정렬 |
| teddy-blue | 위 가운데 곰 | 아래 — y 52~94% |
| bear-blue-sky | 위쪽 풍선·곰, 아래 무지개 | 가운데 띠 — y 46~80% |
| pink-ribbon-arch | 아치 위 리본 | 아치 안 리본 아래 — x 16~84%, y 40~90% |
| pink-ribbon-mono | 가운데 리본 띠 | 리본 위 — y 8~42% (본문은 내용 면으로) |
| party-balloons-cake | 원 + 가장자리 풍선 + 아래 케이크 | 원 안에 제목부만 — x 30~70%, y 12~36% / 본문은 내용 면 |
| pink-castle | 위 가운데 성 | 성 아래 — x 14~86%, y 56~92% |
| sage-teddy | 리본 프레임 + 아래 곰 | 프레임 안 곰 위 — x 22~78%, y 20~62% |
| pressed-flowers | 가장자리 꽃 + 흰 패널 | 흰 패널 — x 26~74%, y 16~88% |
| lavender-peony | 꽃 + 안쪽 프레임 | 프레임 안 — x 14~86%, y 12~88% |

- `black-gold-gala`: 영역 불필요, 글자색을 금색 계열로(`colorMain`) — 대비 4.5:1 이상
- `iris-hearts`(감사 카드, 1080 정사각): 흰 종이 위에 글이 오도록 영역 지정 또는 내리기 — 점검 후 판정

### 5.3 영역 안 맞춤

- 가로: 기존 `FitText` 그대로 (영역 폭이 컨테이너)
- 세로: 제목부(라벨+부제+제목+본문)의 실제 높이가 영역 높이를 넘으면 ① 본문을 내용 면으로 내림 → ② 그래도 넘으면 제목 크기를 최소값(18px)까지 단계 축소 → ③ 그래도 넘으면 부제를 내용 면으로
- 측정은 `FitText` 와 같은 방식(레이아웃 전 측정, ResizeObserver) — 순수 함수 `planZone(heights, zoneH)` 로 분리해 단위 테스트

### 5.4 봉투 → 카드 연출

- 현재 흐름 유지: 봉투 표시 → 탭 → 카드. 새 구조에서는 **표지가 봉투에서 위로 올라온 뒤(약 600ms), 내용 면이 아래로 펼쳐지는** 2단 연출
- `prefers-reduced-motion` 이면 연출 없이 바로 표시
- 9개 봉투 종류 전부를 샘플 카드로 열어 보고(개발용 페이지) 깨지는 조합 수정
- 개발용 페이지에 "봉투부터 보기" 모드 추가 — DB 없이 봉투→카드 전체 흐름 확인

### 5.5 전체 점검과 새 템플릿

- *(사용자 확정, 2026-11-22)* 영역을 줘도 도저히 안 되는 템플릿은 디자인 자체를 고치거나 내려도 된다 — 판정은 빌더가 하고 결과를 보고
- 25개 판정표를 만들고(유지/영역/색/교체) 사용자에게 스크린샷으로 확인받는다
- 교체 대상(예상 0~3개: 영역을 줘도 글 자리가 너무 좁은 것)은 코드로 그린 새 템플릿으로 대체 — 같은 분위기(곰돌이·풍선 → 파스텔 도형·깃발 등)로, SVG 장식 + 처음부터 정의된 글 영역
- 기존 발행 카드: 템플릿을 내려도 발행된 카드는 계속 그 배경으로 열려야 함 → 내린 템플릿은 `draft: true`(새 카드 선택 목록에서만 제외), 배경·렌더는 유지

### 5.6 관리자·미리보기

- 관리자 템플릿 화면과 카드 만들기 미리보기는 같은 카드 컴포넌트를 쓰므로 자동 반영
- 개발용 `/typography-demo` 에 `?zones=1` (영역 테두리 표시) 추가 — 영역 값 보정용

## 6. 빌더에게 맡기는 것

- 영역 수치 최종값(위 표는 추정), 내용 면 색, 연출 타이밍·이징, 새 템플릿의 구체 디자인
- 파일 분리(새 렌더러를 `ClassicTemplateCard` 안에 넣을지 별도 `ZoneTemplateCard` 로 둘지 — 200줄 규칙상 별도 권장)

## 7. 검증

- 25개 × (짧은/긴 영문/한글 제목) × (짧은/긴 본문) × 375·440px 스크린샷 — 글·박스가 영역과 내용 면 밖으로 안 나감, 그림 위치 불변
- `planZone` 단위 테스트(정상/경계/넘침)
- 봉투 9종 × 샘플 카드 열기 확인
- 확인 불가: 실제 발행 카드(DB 필요) — 사용자 확인 항목
