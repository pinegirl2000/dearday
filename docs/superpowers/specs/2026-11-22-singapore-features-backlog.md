## 채택 (사용자: "이거 좋고")
1. **캘린더에 추가** — 확정된 일정을 Google·Apple 캘린더에 한 번에 넣는 버튼
2. **WhatsApp 중심 흐름** — 그룹 공유용 미리보기, RSVP 마감 전날·행사 전날 리마인더
3. **공휴일·학교 방학 표시** — 날짜 선택 시 싱가포르 공휴일·학교 방학·음력 날짜 표시 (만월·설)
4. **식단 수집** — RSVP 에서 할랄·채식·알레르기
5. **테이블 인원 집계** — 주최자 화면에 10명 테이블 단위 집계 ("현재 3테이블 + 4명")
6. **PayNow QR** — 축의금·회비용 주최자 QR 표시 (돈은 앱을 거치지 않음)
7. **오시는 길** — 가까운 MRT역·출구, 주차, Grab·Google Maps 바로가기
8. **4개 언어 카드** — 영어·중국어·말레이어·타밀어 문구 전환

## 채택 — 옵션 기능 (사용자: "초대장 만드는 사람이 옵션으로 설정하고 싶으면 해도 될 듯")
9. **날짜 투표 후 확정** — 주최자가 카드 만들 때 켜는 옵션. 후보 날짜 2~4개 → 받는 사람이 가능한 날 선택 → 주최자 확정 → 확정 카드 재발송. 기본은 꺼짐(일반 RSVP)

## 메모

- 설계 시 확인할 것: 개인정보(식단·연락처) 처리 — PDPA, WhatsApp 발송 방식(공유 링크 vs Business API), 음력 변환 방식

## 추가 아이디어 (2026-11-22, 사용자 질문: "목적에 맞게 다양한 문구를 추천받고 그걸 바탕으로 수정할 수 있나")
10. **문구 추천** — 카드 만들 때 행사 목적·말투(격식/친근/유머)·언어를 고르면 제목·한 줄·본문 문구 후보를 여러 개 보여 주고, 고른 것을 바로 편집
    - 현재: 행사별 샘플 문구 1개가 미리 채워짐(`src/lib/templates/sampleData.ts`), 후보 선택 기능은 없음
    - 방식 A(추천): 행사×말투별로 다듬어 둔 문구 모음 — 비용 없음, 즉시 표시, 품질 일정
    - 방식 B: AI 생성(Claude API) — 이름·상황을 반영한 맞춤 문구, 호출 비용·API 키 필요, 부적절 문구 검수 필요
    - A 로 시작하고 "더 만들어 줘" 버튼에만 B 를 붙이는 조합 가능
