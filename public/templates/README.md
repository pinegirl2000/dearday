# DearDay Templates

이 폴더에 8개 PNG 파일을 업로드해주세요.

## 파일 명명 규칙

각 template당 2개 파일:
- `template-{N}-bg.png` — 배경 이미지
- `template-{N}-layout.png` — 텍스트 레이아웃 가이드 (디자인 참조용)

## 업로드해야 할 파일 (총 8개)

```
template-1-bg.png       (template 1 배경)
template-1-layout.png   (template 1 텍스트 레이아웃 가이드)
template-2-bg.png       (template 2 배경)
template-2-layout.png   (template 2 텍스트 레이아웃 가이드)
template-3-bg.png       (template 3 배경)
template-3-layout.png   (template 3 텍스트 레이아웃 가이드)
template-4-bg.png       (template 4 배경)
template-4-layout.png   (template 4 텍스트 레이아웃 가이드)
```

## 권장 사양

- **배경 (bg)**: 모바일 사이즈 (840 x 1400px, 2x 디스플레이 대응), 1MB 이하
- **레이아웃 (layout)**: 텍스트 위치 가이드 이미지 (이를 참고해 CSS 작성)
