## 디자인 컨셉

- **Hydrangea (보라수국)** — 부드러운 곡선과 수국 꽃잎 SVG. 가족 중심 의례에 적합
- **Modern** — 진한 네이비 + 골드 라인, 직선 그리드. 도시적·비즈니스 친화
- **Vintage** — 종이 텍스처 + 1920s 아르데코 풍. 격조 있는 무드
- **Minimal** — sage green 포인트 + 타이포그래피 위주. 컨템포러리
